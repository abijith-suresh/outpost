# apps/cli — agent brief

The only published workspace: `@abijith-suresh/outpost`, shipping the `outpost` binary plus an import-safe `runCli()` API.

## The Project
Core promise: this package is the whole product, and refusals are the feature. Removal refuses dirty worktrees and foreign or modified guidance, and creation rolls back rather than leaving partial state.
Non-goals: no push, pull, merge, or remote mutation beyond fetching managed mirrors.
